写真からクロスステッチ図案を自動生成

お手持ちの写真をアップロードするだけ。DMC・オリンパスの糸番号に自動マッチング、記号入り図案とPDFを無料でダウンロードできます。

今すぐ無料で使う →

このツールでできること

🪡 写真から自動変換

JPG/PNGの写真をアップロードするだけで、指定したマス数のクロスステッチ図案に自動変換します。

🎨 DMC・オリンパス対応

DMC糸番号489色＋オリンパス糸番号にも対応。実際に手に入る糸の色に自動マッチング。

📄 PDFダウンロード

図案・色凡例・必要な糸量をまとめたPDFをダウンロードして、印刷して使えます。

✂️ 背景マスク機能

背景を塗りつぶしてキャラクターだけ図案化、といった編集もブラウザ上でできます。

🔠 記号入りチャート

各色に記号を割り当てた白黒チャートも生成。色覚に頼らず刺せます。

💸 完全無料で使える

30マス×4色までは無料、それ以上は有料アンロックで生涯利用可能（買い切り）。

使い方は3ステップ

写真をアップロード

ペット・お子さん・推しキャラなど、図案化したい写真を選びます。

サイズ・色数を指定

布のカウント数、幅（マス数）、使いたい色数を選びます。

生成してダウンロード

図案プレビュー・PDF・糸量リストが即時生成されます。
